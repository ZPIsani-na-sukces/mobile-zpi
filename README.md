# mobile-zpi

Aplikacja mobilna Flutter dla projektu ZPI (ZPIsani na sukces).

## Wymagania

- [FVM](https://fvm.app/) — Flutter **3.47.2**
- Xcode (iOS) / Android SDK (Android)

## Setup

```sh
fvm install
fvm flutter pub get
fvm flutter run
```

IDE (VS Code / Cursor) powinno automatycznie użyć SDK z `.fvm/flutter_sdk`.
